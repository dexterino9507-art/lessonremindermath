# Бот напоминаний об уроках

Каждые 15 минут бот читает Google Календарь, сопоставляет уроки с базой «Ученики» в Notion (поле «Из расписания», несколько названий разделяются знаком `/`) и отправляет напоминания в Telegram:

- за 24 часа — с кнопками «Подтверждаю» и «Нужен перенос»;
- за 2 часа — повторно, с кнопками, если ответа не было;
- за 3 часа без подтверждения — сигнал преподавателю.

Запрос на перенос сразу пересылается преподавателю. Все статусы сохраняются в базе «Напоминания об уроках» в Notion.

## Настройка (один раз, около 20 минут)

### 1. Бот в Telegram
1. Откройте @BotFather, отправьте `/newbot`, задайте имя и адрес бота.
2. Сохраните выданный токен — это `TELEGRAM_BOT_TOKEN`.

### 2. Доступ к Notion
1. Откройте https://www.notion.so/profile/integrations → «New integration», тип Internal.
2. Скопируйте Internal Integration Secret — это `NOTION_TOKEN`.
3. Откройте страницу «Учебный центр» → меню `•••` → «Connections» → добавьте созданную интеграцию.

### 3. Адрес календаря
1. Google Календарь в браузере → «Настройки» → в списке слева выберите свой календарь.
2. Раздел «Интеграция календаря» → «Секретный адрес в формате iCal». Скопируйте ссылку — это `GCAL_ICS_URL`.

Ссылку никому не передавайте: по ней видно всё расписание.

### 4. Репозиторий GitHub
1. Создайте репозиторий и загрузите в него содержимое этой папки (вместе с папкой `.github`).
2. Тип репозитория:
   - **публичный** — минуты GitHub Actions бесплатны без ограничений. Личных данных в коде нет, ключи хранятся в Secrets;
   - **приватный** — бесплатно 2000 минут в месяц. В файле `.github/workflows/reminders.yml` замените `*/15` на `*/30`.
3. Settings → Secrets and variables → Actions → New repository secret. Добавьте:
   - `TELEGRAM_BOT_TOKEN`
   - `NOTION_TOKEN`
   - `GCAL_ICS_URL`
4. Там же, вкладка Variables, по желанию добавьте `POLICY_TEXT` — текст правила, который добавится к напоминанию за сутки. Например: «Отмена менее чем за 24 часа: урок считается проведённым.»

### 5. Идентификатор преподавателя
1. Отправьте своему боту `/start`.
2. GitHub → Actions → «Напоминания об уроках» → Run workflow.
3. Бот ответит: «Ваш идентификатор: …». Добавьте это число в Secrets как `TUTOR_CHAT_ID`.

### 6. Подключение учеников и родителей
1. Отправьте боту `/links` и запустите workflow вручную (или подождите до 15 минут).
2. Бот пришлёт по две ссылки на каждого ученика: первая для ученика, вторая для родителя.
3. Разошлите ссылки. После нажатия «Старт» в базе «Ученики» заполнится Chat ID, и напоминания начнут приходить.

## Команды преподавателя
- `/links` — ссылки для подключения и отметки, кто уже подключён.
- `/check` — события календаря на неделю, для которых не найден ученик, и ученики без Telegram.

## Ограничения
- Бот отвечает с задержкой до 15 минут: он запускается по расписанию, а не работает постоянно. GitHub иногда запускает задачи с опозданием ещё на 5–15 минут, поэтому второе напоминание отправляется за 2 часа, а не за 1.
- Новое событие в календаре должно называться так же, как в поле «Из расписания». Проверка — команда `/check`.
- В публичном репозитории GitHub отключает расписание после 60 дней без изменений в репозитории и присылает письмо. Включается одной кнопкой на вкладке Actions.
